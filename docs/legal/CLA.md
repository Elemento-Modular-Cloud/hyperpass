# Elemento contributor licence agreement

Electros LaunchPad stays **GNU GPLv3**. This CLA does not replace that licence, does not
relicense Canonical’s Multipass code, and does not assign your copyright to Elemento.

It covers **new contributions** you submit to Elemento projects (including this repository).
You keep copyright. Elemento S.r.l. receives a licence to use, sublicense, and relicense
that contribution — including under commercial or proprietary terms — and must also keep
licensing it under the project licence in effect when you submitted it (GPLv3 here).

The combined Electros LaunchPad program remains GPLv3 because it still contains
GPLv3 Multipass material.

## Agreements

- [Individual CLA](CLA-individual.md) — sign this if you contribute as yourself
- [Entity CLA](CLA-entity.md) — your employer or company must sign this if the
  contribution belongs to them

These texts are based on the [Harmony Contributor Licence Agreement](http://harmonyagreements.org/).

## How to sign

1. Read the [Individual CLA](CLA-individual.md). If you contribute for an employer,
   they must also agree to the [Entity CLA](CLA-entity.md) (email
   [contact@elemento.cloud](mailto:contact@elemento.cloud)).
2. Add your GitHub username to [`cla/SIGNERS`](../../cla/SIGNERS) in the same pull
   request (or in a prior one). One username per line, no leading `@`.
3. Tick the CLA box on the pull request template.

Adding your username to `cla/SIGNERS` is your signature. One signature covers later
contributions to Elemento projects that use this CLA.

Members and owners of the `Elemento-Modular-Cloud` GitHub organisation are treated as
already covered when they author the pull request.

## Third-party material

If you do not own the copyright in the entire contribution (for example it includes
someone else’s code, or work you did for an employer that has not signed the Entity
CLA), do not submit it. Email [contact@elemento.cloud](mailto:contact@elemento.cloud)
and describe the material first.

## What this does not do

- It does not change GPLv3 on existing Multipass code or on the public Electros
  LaunchPad sources.
- It does not give Elemento exclusive rights; you may still use and licence your own
  contribution elsewhere.
- It does not let Elemento distribute the combined LaunchPad binary as proprietary
  software while Canonical’s GPLv3 code remains in that binary.
